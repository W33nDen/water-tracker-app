# Tech Stack — WaterTracker

## Frontend

| Параметр | Значення |
| :--- | :--- |
| Фреймворк | React 18 |
| Стан застосунку | Zustand (або Redux Toolkit) |
| Маршрутизація | React Router DOM v6 |
| Стилізація | Tailwind CSS |
| Збірка | Vite |

**Чому обрали:**
- **React + Vite:** Забезпечує миттєвий Hot Module Replacement (HMR) та швидку збірку порівняно з CRA.
- **Tailwind CSS:** Дозволяє гнучко налаштувати кастомні брейкпоінти за ТЗ (`320px`, `768px`, `1440px`) та швидко будувати адаптивний UI без написання надлишкового CSS-коду.
- **React Router DOM:** Стандарт для SPA з декларативним захистом приватних і публічних маршрутів.
- **Zustand:** Легковажний менеджер стану з простим синтаксисом, що ідеально підходить для збереження сесії користувача та щоденних порцій води без бойлерплейту.

## Backend

| Параметр | Значення |
| :--- | :--- |
| Мова | JavaScript (Node.js) |
| Фреймворк | Express.js |
| База даних | PostgreSQL |
| ORM / драйвер | Prisma ORM |
| Автентифікація | JWT (Access Token + Refresh Token) |
| Документація API | Swagger UI (`swagger-ui-express`) |

**Чому обрали:**
- **Express.js:** Мінімалістичний та перевірений часом фреймворк, чудово комбінується з будь-якими middleware для обробки помилок, CORS та валідації.
- **PostgreSQL + Prisma:** Реляційна структура оптимальна для сутностей `User` та `WaterRecord` (зв'язок один-до-багатьох). Prisma забезпечує типобезпеку, автоматичні міграції та зручний клієнт запитів.
- **JWT:** Дозволяє реалізувати stateless-авторизацію. Для узгодження ТЗ токен доступу передається через заголовок `Authorization: Bearer <token>`, а сесія оновлюється через Refresh Token.
- **Swagger:** Пряма вимога ТЗ мати інтерактивну документацію за окремим маршрутом (`/api-docs`).

## Інфраструктура

| Параметр | Значення |
| :--- | :--- |
| Хостинг frontend | Vercel / Netlify |
| Хостинг backend | Render / Railway |
| Хмарне сховище | Cloudinary |

**Чому обрали:**
- **Vercel:** Безшовна інтеграція з GitHub, автоматичний деплой при злитті в гілку `main`, швидкий CDN.
- **Render/Railway:** Надають безкоштовний/тестовий хостинг для Node.js сервісів та керовану базу даних PostgreSQL.
- **Cloudinary:** Спеціалізований сервіс для завантаження, оптимізації та зберігання аватарів користувачів через API без перевантаження сервера статикою.
